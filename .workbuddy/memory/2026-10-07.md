### 机制（可复现，新增题目只需补一条映射）

- **用跳转页而非 nginx 301**：当前索引量近零，跳转页已足够（用户不撞 404 + 搜索引擎合并信号），且**零服务器配置改动风险**。索引量上来后再升级为 nginx 301（`configure-server-seo.py` 已有备份/回滚骨架）。
- **顺带修掉一个部署阻塞**：`img-src/Q017/01-rule-and-exception-split.png` 损坏（458 KB、缺 IEND，正常 2.1 MB），会让 `npm run build` 的 `img:optimize` 崩溃 → 整条部署失败。已用 `watermark-images.py --only=Q017` 从写作仓库原始素材幂等重生成。
- **构建顺序坑（重要）**：`img:optimize` 写 `public/img/`，必须再跑一次 `astro build` 才会复制进 `dist/`。只跑 `img:optimize + build:post` 会出现「自检报图片不存在」的假故障。
