## 调研：能否同时提交 Google / 百度（结论，已修正）
- **Google：不可行**。`google.com/ping?sitemap=` 2023-06 弃用、现 404；Indexing API 官方仅支持 JobPosting 与 BroadcastEvent（直播）；GSC 的 URL Inspection API 只读、不能触发抓取。Google 侧不存在可每日自动提交的通道。
  - 已实测：两个站线上 robots.txt **都已带 `Sitemap:` 指令**（note → `sitemap-index.xml`，www → `sitemap.xml`，均 HTTP 200），Google 侧配置本就就绪，无需任何自动化。
- **百度：本仓库已有接入点，不需要写新脚本**。`deploy.sh` 的 `push_urls()`（约 210-215 行）已实现普通收录 API 推送：`curl --data-binary @list "http://data.zz.baidu.com/urls?site=https://note.lgdsunday.club&token=$BAIDU_PUSH_TOKEN"`。**唯一缺口是脚本顶部 `BAIDU_PUSH_TOKEN=""` 为空**，填上 ziyuan.baidu.com「普通收录 → API 提交」的准入密钥即生效。
  - 待验证细节：`site=` 参数当前带 `https://` 前缀，百度官方示例是裸域名（`site=www.example.com`）。若填入 token 后返回 `not_same_site` / `site is not valid`，先去掉协议头。
