## 用户问「黑链是否可行」+ 外链建设方案

用户问：如何增加外链？听说「黑链」，是否可行。按白帽原则明确否掉，方案落在 `docs/backlink-plan-2026-10-08.md`。

**黑链否定的依据（已联网核实）**：
- Google：2022-12 链接垃圾更新起由 **SpamBrain** 识别链接网络，处理方式是「**在算法中中和链接价值**」→ 买到的是 0 而非「有风险的收益」；且官方明确「链接垃圾更新后即便事后删链，之前获得的排名收益也拿不回来」。
- 百度：**惊雷算法** 2017 上线，2018 的 2.0 明确把「在高质量站点植入隐藏链接（黑链）」与买链、站群、群发外链并列为「恶意制造作弊超链」打击对象；3.0（2021）/4.0（2023）持续升级；「计入站点历史，严重者永久封禁」。
- 风险不对称：影响的是**整个域名信任基线**，而本站已握有真实资产（415 篇 + 付费课 + 公众号 + www 主站 284 天数据）。
- 唯一「合法花钱」替代：付费赞助/广告位，**必须 nofollow/sponsored**，只买曝光不买权重。

**渠道优先级（结论）**：P0 自有资产互链（www→note / GitHub About+Topics / 公众号阅读原文）> P0 知乎高质量回答（百度·必应收录最快）> P1 课程平台讲师页、掘金·思否导读型长文、可被引用型资产（速查表 / Token 估算器 / 415 题数据报告）> P2 awesome-* PR、导航站收录 > P3 同领域友链（≤5 个）。

**重要判断**：外链只是 Bing 问题的一个变量；短期最确定带来点击的仍是已收录页面的排名 + **SERP 标题描述优化**（见 `docs/audit-Q376-Q415-2026-10-08.md` 第二项）。并已如实说明「同主体互链对 Google 权威传递有限」，不要误导用户。

**待用户决策**：www → note 的导航/页脚互链需授权改动 www；知乎/掘金/课程平台只能用户本人做；速查表·工具页·数据报告属我职责，待发令。
