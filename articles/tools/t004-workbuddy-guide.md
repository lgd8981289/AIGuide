## 工作模式与工作区

WorkBuddy 可以修改本地文件，所以咱们的第一次使用，最好是先创建一个临时工作区，先熟悉熟悉它的调性。

先在桌面新建一个文件夹，就叫做 “WorkBuddy 入门练习”

然后从电脑里找几份不重要的文件，复制到这里，我这里放了一点 md 文档、图片、xmind 脑图啥的

![「WorkBuddy 入门练习」文件夹中的内容](https://note.lgdsunday.club/img/T004/image-20260917120200308.webp)

这个文件夹，就可以作为咱们的 **工作空间**

你可以把工作空间理解成：这一次任务里，WorkBuddy 的可操作区域

我们可以直接在  WorkBuddy 里面，找到 选择工作空间，打开本地文件夹，选中当前的文件夹即可

![对话输入框中的斜杠命令菜单](https://note.lgdsunday.club/img/T004/image-20260917120249709.webp)

官方文档里把这个目录叫做**工作空间**。

新建任务时，WorkBuddy 目前提供三种工作方式。

![斜杠命令菜单中的规划类选项](https://note.lgdsunday.club/img/T004/image-20260917120426201.webp)

- 第一种 **默认模式** 也就是 Agent 模式。这种模式下会根据指令直接执行任务，可以创建和修改文件。
- 第二种 **仅问答** 也就是 Ask 模式。适合查资料、问思路和讨论方案。它主要回答问题，不会直接执行文件修改。
- 第三种 **计划**  也就是 Plan 模式。它会先读取任务需要的信息，给出准备怎样处理、可能修改哪些内容，等你确认以后再进入执行。

咱们这一次就先选择 `Plan` 模式就可以

### 提示词应该怎么写？

如果大家仔细看咱们上面的提示词，就会发现，这个提示词其实还挺复杂的。

很多同学不会写提示词，这里给大家说一下写提示词的技巧

使用 Agent 时，我建议大家至少把下面五件事交代清楚：

1. **目标**：最后想得到什么结果。
2. **材料**：需要读取哪些文件、目录或者外部数据。
3. **边界**：哪些可以修改，哪些绝对不能碰。
4. **交付物**：最终要生成什么文件，放在哪里。
5. **验收方法**：怎样证明任务真的完成了。

比如 “整理文件夹” 只是一个动作。

而“文件数量不能减少、同名文件不能覆盖、无法判断的单独放置，并生成移动记录”，才让这个任务有了可以检查的结果。

这套写法不只适用于 WorkBuddy。

以后让 Codex 修改代码、让浏览器 Agent 检查网页、让 AI 分析表格，本质上都一样。

## Skill 技能：把反复做的工作，变成一套固定方法

假设这周咱们让 WorkBuddy 生成了一份项目周报。

下周再做时，还是要重新告诉它一遍所有的事情。

下下周，还得再说一遍。

你不想这么麻烦，那么就需要 Skill 了。

Skill 解决的是 “以后遇到这一类任务，Agent 应该固定按照什么方法做的问题”。

所以，一个任务是否值得做成 Skill，主要看两个条件：

- 第一：这件事是不是会反复出现。
- 第二：它的处理步骤和质量标准是不是相对固定。

咱们打开 WorkBuddy 左侧的 Skill 页面

![左侧菜单中的新会话与制定方案入口](https://note.lgdsunday.club/img/T004/image-20260917131006978.webp)

## 记忆：让 WorkBuddy 记住你

假设咱们已经告诉 WorkBuddy：

> 我正在学习 AI，希望用 5 个月入门
>
> 我更喜欢通过实际案例来学习
>
> 讲解概念时，尽量说得简单一点。

这些信息如果每次新建对话都要重新说一遍，也挺麻烦的。

所以，WorkBuddy 提供了 **记忆功能**。

WorkBuddy 会从咱们平时的对话中，整理出可能长期有用的信息。

按照目前官方的说明：**WorkBuddy会在每天晚上整理当天的对话，并把其中一部分内容保存成记忆。**

咱们点击头像，进入“设置”，再找到“记忆与进化”。

![WorkBuddy 对话界面与左侧菜单](https://note.lgdsunday.club/img/T004/image-20260917135340993.webp)

在这里，可以直接看到 WorkBuddy 到底记住了什么（因为演示用的是新账号，所以这里没有数据）。

![设置中的「记忆与进化」页面](https://note.lgdsunday.club/img/T004/image-20260917135422046.webp)

当然，记忆也有可能总结错。

所以，大家可以在“记忆与进化”中修改或者删除不准确的内容，不希望 WorkBuddy 保存记忆的话，也可以直接关闭这个功能。

## 个性化：让 WorkBuddy 按照你的习惯工作

记忆是 WorkBuddy 从平时的对话中，自己总结出来的信息。

但是有些要求，咱们并不想让它自己猜。

比如：默认使用中文，讲解概念时尽量说人话，信息不够时先问我，不要自己编。

这些长期都希望 WorkBuddy 遵守的要求，可以直接写进 **个性化**。

咱们进入“设置”，打开“个性化”。

![设置中的「个性化」页面，配置语言偏好与回复风格](https://note.lgdsunday.club/img/T004/image-20260917135621331.webp)

在这里，可以设置：称呼、身份、回复风格和自定义指令 等等的东西

比如，咱们可以在自定义指令中写入：

```text
默认使用中文回复。

解释概念时，尽量使用零基础用户能看懂的语言。

生成学习计划时，要给出具体任务，不要只给宽泛的建议。

信息不足时先向我确认，不要自己猜测。
```

保存以后，咱们新建一个对话，随便让 WorkBuddy 解释一个概念，就可以看到这些要求是否生效。

![「配置记忆」页面](https://note.lgdsunday.club/img/T004/image-20260917135753696.webp)

## 定时任务：让任务自动化执行

到这里，咱们已经完成了几件事。

WorkBuddy 能读取工作空间，Skill 规定了周报怎样整理，连接器可以把结果写入外部软件，自定义指令又补上了长期规则。

接下来，才适合考虑定时任务。

我特别不建议刚打开 WorkBuddy，就直接创建一个“每天自动完成所有工作”的任务。

定时任务不是用来验证想法的。

它更适合把已经手动跑通、结果也检查过的流程，交给 WorkBuddy 定时重复。

比如，我可以让每周末 WorkBuddy 自动去分析腾讯文档的学习数据

咱们打开左侧的定时任务，点击新建任务。

![添加记忆的弹窗](https://note.lgdsunday.club/img/T004/image-20260917140010597.webp)

想要做什么定时任务，在这里写上对应的任务名字与提示词就可以了。

同时还可以设置 执行频率 与 当前这次任务的有效期
